# AgentSec Lab

An open-source security research lab for investigating identity, authorization, trust boundaries, and containment in agentic AI systems.

## Research Objective

Evaluate whether security architectures can contain compromised or malicious AI agents independently of model-level safety mechanisms.

## Research Areas

- Agent identity and delegated authorization
- MCP security
- Confused deputy vulnerabilities
- Cross-tenant isolation
- Credential replay and misuse
- Excessive agent permissions
- Agent-to-agent trust
- Attack-path and blast-radius analysis

## Methodology

Each research lab includes:

1. Vulnerable reference implementation
2. Threat model and security assumptions
3. Reproducible proof of concept
4. Hardened reference implementation
5. Security regression tests
6. Architectural recommendations

## Research Principles

- Evidence over assumptions
- Authorization independent of model behavior
- Explicit trust boundaries
- Reproducible security findings
- Defense informed by offensive research

## Responsible Use

All experiments are designed for isolated, authorized research environments using synthetic data.
